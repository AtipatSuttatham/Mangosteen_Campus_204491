# Mangosteen Campus

เว็บแอปพลิเคชันระบบจัดการการเรียนรู้ (Learning Management System: LMS) ที่ผสมการจัดการเนื้อหาเข้ากับการประเมินผลและการจัดการคะแนนไว้ในระบบเดียว

> การค้นคว้าอิสระ กระบวนวิชา 204491 สาขาวิชาวิทยาการคอมพิวเตอร์ คณะวิทยาศาสตร์ มหาวิทยาลัยเชียงใหม่ ปีการศึกษา 2569

## ความสามารถหลัก

- ผู้ใช้ 3 บทบาท: **ผู้ดูแลระบบ** / **ผู้สอน** / **ผู้เรียน** (ผู้ดูแลระบบเป็นผู้สร้างบัญชีทั้งหมด)
- จัดการรายวิชาและการลงทะเบียนเรียน ทั้งเพิ่มรายชื่อโดยตรงและเข้าร่วมด้วยรหัสเข้าร่วมรายวิชา
- จัดการเนื้อหาแบบมีลำดับชั้น: รายวิชา → หน่วยการเรียน → เนื้อหา (ข้อความ ไฟล์ รูปภาพ เสียง วิดีโอ ลิงก์)
- แบบทดสอบ 5 ชนิดคำถาม พร้อม**การสอบย่อยแบบจับเวลาที่บังคับฝั่งเซิร์ฟเวอร์**และส่งคำตอบอัตโนมัติเมื่อหมดเวลา
- การสั่งงานและส่งงาน พร้อมทำเครื่องหมายงานที่ส่งช้า
- สมุดคะแนนแบบ**ถ่วงน้ำหนักตามหมวดคะแนน**
- ประกาศข่าวสารในรายวิชา
- การจำลองมุมมองผู้ใช้ และประวัติการใช้งาน (Audit Log) สำหรับผู้ดูแลระบบ
- หน้าจอรองรับ 2 ภาษา (ไทย / อังกฤษ)

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| ส่วนหลังบ้าน (Backend) | Python, Django 5.2, Django REST Framework, Simple JWT |
| ส่วนหน้าบ้าน (Frontend) | React, TypeScript, Vite, Tailwind CSS v4 |
| ฐานข้อมูล | PostgreSQL |
| การตรวจอัตโนมัติ (CI) | GitHub Actions |

## วิธีติดตั้งและรันระบบ

ต้องมี: Docker Desktop, [uv](https://docs.astral.sh/uv/), Node.js 24 และ [pnpm](https://pnpm.io/)

```
# 1) สร้างไฟล์ตั้งค่า แล้วแก้รหัสผ่าน / secret key / พอร์ต
Copy-Item .env.example .env

# 2) เปิดฐานข้อมูล PostgreSQL
docker compose up -d

# 3) ติดตั้งแพ็กเกจและเปิดส่วนหลังบ้าน
cd backend
uv sync
uv run python manage.py runserver 8008

# 4) (อีกหน้าต่างหนึ่ง) ติดตั้งแพ็กเกจและเปิดส่วนหน้าบ้าน
cd frontend
pnpm install
pnpm dev
```

ตรวจว่าระบบทำงาน: เปิด http://localhost:5180 → ต้องเห็นวงกลมสีเขียวและ `{"status":"ok","database":"ok"}`

รายละเอียดทีละขั้น เรื่องพอร์ต และวิธีแก้ปัญหา อยู่ใน [`WORKFLOW_GUIDE.md`](WORKFLOW_GUIDE.md)
