| จับคู่ — จำนวนคู่ขั้นต่ำ (ผู้ใช้ขอ 2026-11-23) | **มีคู่เดียวได้ แต่ผู้เรียนต้องมีตัวเลือกอย่างน้อย 2 แบบ** (นับแบบไม่ซ้ำ) — คู่เดียวจึงต้องมีตัวหลอกอย่างน้อย 1 ตัว ไม่อย่างนั้นช่องเลือกมีคำตอบเดียว ได้คะแนนฟรี |
| เติมคำ — วิธีสร้าง (ขส3 — **แทน ขพ1** ที่ให้พิมพ์ `[1]` `[2]` แล้วกรอกกล่องตัวเลือกแยก) | เขียนคำตอบไว้ในโจทย์เป็น **`{{คำตอบที่ถูก \| ตัวหลอก \| ตัวหลอก}}`** (คำแรกคือคำตอบที่ถูกเสมอ) ; สร้างได้ 2 ทาง: **เลือกคำในโจทย์แล้วกด "ทำเป็นช่องว่าง"** หรือพิมพ์เอง ; ระบบนับเลขช่องตามตำแหน่งในโจทย์เอง ; ใต้โจทย์มี**แถบรายการช่อง** (คำตอบที่ถูก + ตัวหลอกเป็นป้าย) ที่ซิงก์กับโจทย์ทั้งสองทาง + **กล่องตัวอย่างสด "ผู้เรียนจะเห็น"** ; ช่องโจทย์ใช้ตัวอักษรแบบโค้ด ; ไม่เพิ่มไลบรารีตัวแก้ไขข้อความ — **เหตุผลที่เปลี่ยน**: แบบ `[1]` ชนกับโค้ด Python เช่น `nums[1]` (ต้องพิมพ์ `\[1\]` ทุกครั้ง ลืมง่าย), ผู้สอนต้องสลับไปมาระหว่างโจทย์กับกล่อง และเลขช่องพังเมื่อแทรกช่องกลางโจทย์ ; ใช้ `{{ }}` ไม่ใช้ `[[ ]]` เพราะชนกับลิสต์ซ้อน `[[1, 2], [3, 4]]` |
| ข้อความเตือนเมื่อบันทึกไม่ได้ (ขฬ1) | ช่องที่ผิดขอบแดง + ข้อความใต้ช่องบอก**จุดที่ผิดและวิธีแก้** (เช่น "ช่องที่ 2 ยังไม่มีวงเล็บปิด เติม `}}` หลัง…", "`int` เป็นคำตอบของคู่ที่ 1 และ 3 อยู่แล้ว…") ผูกกับช่องด้วย `aria-describedby` ; แถบล่างสรุป "แก้ N จุด…ก่อนบันทึก" + ปุ่มบันทึกใช้ `aria-disabled` (กติกาโฟกัส กภ1) ; เติมคำที่วงเล็บไม่ครบ กล่องตัวอย่างแสดงถึงช่องที่ถูกต้องเท่านั้น |

|---|---|

| ทำได้หลายครั้ง | ระบบนับ**ครั้งที่ได้คะแนนสูงสุด** + ป้าย ★ "ครั้งที่นับ" |
| คะแนนต่อข้อ | ทศนิยม 2 ตำแหน่ง ค่าเริ่ม 1 ; จับคู่ / เติมคำแบ่งคะแนนเท่ากันทุกคู่ / ช่อง ผู้เรียนได้ตามจำนวนที่ถูก |
| ก่อนส่ง / ออกจากหน้า | ถามก่อนออกจากหน้าระหว่างทำ (`useLeaveGuard`) ; หน้าต่างยืนยันส่งแสดงรายการข้อที่ยังไม่ตอบ / ตอบไม่ครบ พร้อมลิงก์ไปที่ข้อ |
| เผยแพร่ / ลบ / แก้ | เผยแพร่ได้เมื่อมีคำถามอย่างน้อย 1 ข้อ ; ยกเลิกเผยแพร่ได้ ; **ลบได้เฉพาะที่ไม่เคยเผยแพร่** ; หลังมีผู้เรียนทำแล้ว แก้ได้เฉพาะชื่อ คำอธิบาย และช่วงเวลาเปิด-ปิด (คำถามถูกล็อก — กันคะแนนที่ตรวจไปแล้วไม่ตรงกัน) |
| AuditLog | จด `delete` (แบบทดสอบ) และ `grade` (ตรวจอัตนัย) |
| ผู้ดูแลระบบ | ดูแบบทดสอบได้อย่างเดียว (ตามกติกาเนื้อหาของก้อน 4) — ไม่มี board แยก |

## หมายเหตุสำหรับคนแก้ wireframe

- **canvas ตีความ `{{ … }}` เป็นคำสั่งของตัวเอง** (แสดงเป็น `[object Object]`) แม้เขียนเป็นรหัส HTML `&#123;` ก็ยังโดน — board ที่ต้องแสดงวงเล็บปีกกาคู่ (เติมคำ, ข้อความเตือน) ใส่อักขระความกว้างศูนย์ `&#8203;` คั่นระหว่างวงเล็บสองตัว ; ระบบจริง (React) ไม่มีปัญหานี้
- ข้อมูลตัวอย่างในทุก board ใช้ชุดเดียวกัน: "แบบทดสอบท้ายหน่วยที่ 3" 6 ข้อ 10 คะแนน (ข้อ 3 จับคู่ค่ากับชนิดข้อมูล, ข้อ 4 เติมคำ, ข้อ 5 ปรนัยที่มีคลิป + ตัวเลือกเป็นรูปผังงาน) — แก้ข้อหนึ่งให้ไล่แก้ทุก board ที่แสดงข้อนั้น

## สิ่งที่ต้องทำในขั้นถัดไป (บันทึกไว้ไม่ให้หลุด)

- **ขั้น 5.2** (ตาราง): ย้าย "สุ่มลำดับ" และ "แสดงผลรายข้อ" ออกจาก `docs/database.md` §13 เข้าสเปกหลัก + บันทึก §11 ; เพิ่มช่องใน `Quiz` (สุ่มข้อ, สุ่มตัวเลือก, แสดงถูก/ผิดรายข้อ, หน่วยที่เชื่อม) + โครงเก็บไฟล์สื่อของโจทย์ (≤ 3 ไฟล์ เรียงลำดับได้) และรูปของตัวเลือก / ฝั่งซ้ายจับคู่ + ตัวหลอกของจับคู่ + รูปแบบ `{{ }}` ของเติมคำ — แก้ docs ทั้ง 4 ไฟล์ให้สอดคล้องกัน
