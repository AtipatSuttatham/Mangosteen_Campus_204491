| หน้าของผู้เรียน (ขั้น 3.7) | ผู้ใช้เลือก 2026-11-08 ; ที่อยู่ **`/courses`** และ **`/courses/{id}`** ใช้ร่วมกับผู้สอน สลับหน้าตามบทบาท (`pages/courses/CourseRoutes.tsx`) ; ผู้เรียนเปิด `/courses/{id}/settings` ได้ "ไม่พบรายวิชา" ; เมนู "รายวิชาของฉัน" ของผู้เรียน ; **เข้าร่วมสำเร็จ → อยู่หน้าเดิม** แถบเขียว + วิชาใหม่โผล่ในรายการ (เปิดกลุ่มภาคของวิชานั้น) + พับส่วนเข้าร่วม (ฟ1 ตาม board) ; **กรอกรหัสของวิชาที่อยู่แล้ว → แถบเทา** "คุณอยู่ในรายวิชา … อยู่แล้ว" (ภ1 — หน้าเว็บแยกจาก HTTP 201 / 200 ผ่าน `apiFetchWithStatus()` ไม่แก้ backend) ; **คำอธิบายรายวิชาแสดงแบบ Markdown** ด้วย `react-markdown` (ม1 — `skipHtml` ทิ้ง HTML ดิบ, ลิงก์ `javascript:` ถูกล้าง, ลิงก์เปิดแท็บใหม่ ; หัวข้อในข้อความเป็น h3 / h4 ไม่แทรกลำดับหัวข้อของหน้า) ; Claude เลือก (มาตรฐาน): ช่องรหัสแปลงเป็นตัวพิมพ์ใหญ่ ตัดช่องว่าง / ขีด ไม่เกิน 8 ตัว ปุ่มกดได้เมื่อครบ 8 ตัว, ไม่ผ่านทุกกรณีใช้ข้อความเดียว `join_code_invalid` และเกิน 10 ครั้ง/นาทีใช้ `throttled`, ชื่อผู้สอนไม่มีคำนำหน้า (ระบบไม่มีช่องเก็บ — board เขียน "อ."), วิชาที่ปิดแล้วมีป้าย "ปิดรายวิชาแล้ว" และเปิดดูได้, ไม่มีคำอธิบาย = ไม่แสดงส่วน "เกี่ยวกับรายวิชา", มือถือแยกการ์ดละวิชา (ตาม board มือถือ), จำค่าพับ/เปิดแยกจากของผู้สอน (`student-courses:*` ในเบราว์เซอร์), แถบข้อความแบบเทา (`Notice` tone `mute`) ; **ยังไม่มีวิชา → ส่วนเข้าร่วมเปิดเสมอ ไม่อ่านค่าที่จำไว้** (ผู้ใช้เลือกแบบ ย1 หลัง PR #37 — ค่าที่จำในเบราว์เซอร์ใช้ร่วมกันทุกบัญชี เครื่องที่ใช้ร่วมกันจึงอาจได้ค่า "พับ" ของคนก่อน ; พับได้ชั่วคราวในหน้า ไม่บันทึก ; ยังไม่แยกค่าที่จำตามบัญชี — พิจารณาทั้งระบบเมื่อมีค่าที่จำมากขึ้น) |
| หน้าของผู้ดูแลระบบ (ขั้น 3.8) | ผู้ใช้เลือก 2026-11-08 ; **หน้า "จัดการรายวิชา" ใช้ที่อยู่ `/courses` เดียวกับผู้สอน / ผู้เรียน** สลับหน้าตามบทบาท (ร1) + เมนู "จัดการรายวิชา" ; หน้ารายวิชา `/courses/{id}` ใช้หน้าเดียวกับผู้สอน ทำแทนได้ทุกอย่าง + **แถบส้ม "คุณกำลังจัดการรายวิชานี้แทนผู้สอน …"** เหนือปุ่มกลับ "จัดการรายวิชา" ; **API ใหม่ `GET /api/v1/admin/courses/teachers/`** รายชื่อผู้สอนทั้งหมดไม่แบ่งหน้า (ล1 — API รายชื่อผู้ใช้เดิมส่งทีละ 20 คน) ใช้ทั้งช่องเลือกผู้สอน (`assignable`) และตัวกรอง "ผู้สอน" (`course_count > 0` รวมบัญชีที่ถูกระงับ) ; **เปลี่ยนผู้สอนต้องยืนยันก่อน** (ว1 — ผู้สอนเดิมหลุดจากวิชาทันที) ใช้ได้แม้วิชาปิดแล้ว ; Claude เลือก (มาตรฐาน): เปิดรายวิชาคืนทำทันที (ย้อนได้ด้วยการปิดอีกครั้ง — ผลขึ้นแถบด้านบนเพราะส่วนสถานะหายไป), ทั้งแถวกดได้ + "จัดการ ›" ท้ายแถวตาม board, มือถือใช้การ์ดแทนตาราง (ไม่มี board มือถือ), ตัวกรองเก็บในที่อยู่ของหน้า, ชื่อผู้สอนในช่องเลือก / ตัวกรองต่อท้ายรหัสพนักงาน (ชื่อซ้ำกันได้ — พบตอนทดสอบใน Chrome), ผู้สอนปัจจุบันที่ถูกระงับแสดงในช่อง "(บัญชีถูกระงับ)" แต่เลือกไม่ได้, สร้างแทนเสร็จพาไปหน้ารายวิชา, ช่องผู้สอนเป็นช่องแรกของหน้าต่างสร้าง (กรอกไม่ครบโฟกัสช่องแรกที่ผิดตามลำดับบนจอ), แถบส้มแสดงตั้งแต่กำลังโหลด (ปุ่มกลับไม่กระโดด) ; **รอบเก็บงาน (PR #40–41)**: เปลี่ยนวิชาแล้วแท็บของหน้ารายวิชาถูกสร้างใหม่ (ค่าที่เลือกค้างไม่ติดไปวิชาอื่น — ศ1), **ตัวกรองบนมือถือช่องละแถวเรียงเหมือนจอใหญ่** (อ1 — ลำดับ Tab ตรงกับที่ตาเห็น), รายชื่อผู้สอน / ภาคเรียนเก็บไว้ใช้ 5 นาทีโดยไม่ขอใหม่ และล้างเองทุกครั้งที่แก้วิชาหรือแก้บัญชีผู้ใช้ (`invalidateUserLists`) ; **รอบปรับโครงสร้างให้แก้ง่าย (PR #42)** (ผู้ใช้เลือกแบบ ฬ2 2026-11-14 — หน้าตาและการทำงานไม่เปลี่ยน): แท็บตั้งค่าแยกเป็นไฟล์ละส่วนในโฟลเดอร์ `pages/courses/settings/` (`SettingsTab.tsx` เหลือเป็นสารบัญ + ลำดับบนจอ ; กติกาปุ่มกลางอยู่ใน `useSettingsActions.ts`) และ**ชื่อแคช + การล้างแคชของหน้ารายวิชาอยู่ใน `pages/courses/courseCache.ts` ที่เดียว — โค้ดใหม่ใช้ชื่อ / ฟังก์ชันจากไฟล์นี้ ไม่พิมพ์ชื่อเอง** |
