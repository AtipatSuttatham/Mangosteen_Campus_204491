# สรุป field ทุกตาราง — LMS (v2.3)

> Quick reference คู่กับ [`database.md`](./database.md) (สเปกเต็ม) และ [`database-erd.md`](./database-erd.md) (ERD) — ตรงกับรายงานตารางที่ 4.3–4.22
> ทุกตารางมี `id` (PK, BigAutoField), `created_at`, `updated_at` — ไม่ลิสต์ซ้ำด้านล่าง (ยกเว้น `AuditLog` มีแค่ `created_at`)
> ชื่อ/หัวข้อทุกตาราง = field เดียว (ไม่แยก `_th/_en`)

---

## 📁 accounts

### `User` — บัญชีผู้ใช้ทุกคน (admin/teacher/student) · ตาราง 4.3
| field | เก็บอะไร |
|---|---|
| `email` | อีเมล (ไม่ซ้ำ, เก็บเป็นตัวพิมพ์เล็ก) — ใช้เข้าสู่ระบบได้ |
| `student_or_staff_id` | รหัสนักศึกษา/รหัสพนักงาน (ไม่ซ้ำ, ว่างได้) — ใช้เข้าสู่ระบบได้ |
| `role` | บทบาทระดับระบบ: `admin` / `teacher` / `student` |
| `first_name`, `last_name` | ชื่อ-นามสกุล |
| `is_active` | บัญชีใช้งานได้ไหม (`false` = ถูกผู้ดูแลระบบระงับ) |
| `avatar_url` | ตำแหน่งไฟล์รูปประจำตัวบนบริการจัดเก็บไฟล์ภายนอก (ว่างได้) — ระบบสร้างลิงก์ให้ ; JPG/PNG/WebP ≤ 2 MB ย่อเหลือ ≤ 512×512 |
| `created_by` | ผู้ดูแลระบบที่สร้างบัญชีนี้ (ว่าง = บัญชีผู้ดูแลระบบเริ่มต้น) |
| `last_login`, `date_joined` | เวลาเข้าสู่ระบบล่าสุด / วันสร้างบัญชี |
| (`password`, `is_staff`, `is_superuser`) | Django จัดการภายใน — ไม่แสดงในรายงาน |

> ไม่มีการสมัครเอง — ทุกบัญชีสร้างโดยผู้ดูแลระบบ

## 📁 academics

### `Course` — รายวิชา (1 วิชา 1 ภาคการศึกษา = 1 แถว) · ตาราง 4.4
| field | เก็บอะไร |
|---|---|
| `academic_year` | ปีการศึกษาที่เปิดสอน เช่น 2569 |
| `semester` | ภาคเรียน: `1` / `2` / `3` (3 = ฤดูร้อน) |
| `teacher` | ผู้สอนที่รับผิดชอบ (1 วิชา 1 คน ; admin สร้างแทนต้องเลือก ; เปลี่ยนได้เฉพาะ admin) |
| `code` | รหัสวิชา เช่น "204111" (ไม่ซ้ำภายในภาคการศึกษาเดียวกัน) |
| `name` | ชื่อวิชา |
| `description` | รายละเอียดรายวิชา |
| `join_code_enabled` | เปิดให้เข้าร่วมด้วยรหัสเข้าร่วมไหม |
| `join_code` | รหัสเข้าร่วม (ไม่ซ้ำ, สุ่มแยกจากรหัสวิชา, ผู้สอนสร้างใหม่ได้) |
| `is_published` | เผยแพร่ให้ผู้เรียนเห็น/เข้าใช้งานได้ไหม |
| `is_closed` | ปิดรายวิชาแล้วไหม (ปิด = ผู้เรียนดูย้อนหลังได้อย่างเดียว) |
| `created_by` | ผู้สร้าง (ผู้สอน หรือผู้ดูแลระบบที่สร้างแทน) |

### `Enrollment` — ตารางเชื่อม: การลงทะเบียนเรียนของผู้เรียน · ตาราง 4.22
| field | เก็บอะไร |
|---|---|

## 📁 assessments (Quiz)

### `Quiz` — แบบทดสอบ / สอบย่อย · ตาราง 4.7
| field | เก็บอะไร |
|---|---|
| `course` | อยู่วิชาไหน (บังคับ) |
| `module` | ผูกกับหน่วยไหน (ไม่บังคับ) |
| `grading_category` | คะแนนเข้าหมวดไหน (ใช้เมื่อ is_graded) |
| `title` | ชื่อแบบทดสอบ |
| `description` | คำอธิบาย (ว่างได้) |
| `is_graded` | เข้าสมุดคะแนนไหม (default True) |
| `time_limit_minutes` | เวลาที่ให้ทำ (นาที) — ว่าง = ไม่จับเวลา |
| `max_attempts` | 1 = ครั้งเดียว / > 1 = หลายครั้งเก็บสูงสุด / ว่าง = ไม่จำกัด |
| `available_from`, `available_until` | ช่วงเวลาเปิด-ปิดรับการทำ |
| `is_published` | เผยแพร่แล้วไหม (เผยแพร่ + is_graded → สร้าง GradeItem อัตโนมัติ) |
| `created_by` | ใครสร้าง |

> คะแนนเต็ม = ผลรวม `Question.points` ; ลบได้เฉพาะที่ไม่เคยเผยแพร่ — เคยเผยแพร่แล้ว → ลบไม่ได้ (ยกเลิกเผยแพร่แทน) ; มีคนทำแล้ว → แก้ได้เฉพาะส่วนที่ไม่กระทบผลเดิม

### `Question` — คำถามในแต่ละแบบทดสอบ · ตาราง 4.8
| field | เก็บอะไร |
|---|---|
| `quiz` | อยู่แบบทดสอบไหน |
| `question_type` | `mcq` / `true_false` / `matching` / `dropdown` / `short_answer` |
| `text` | โจทย์ (dropdown ระบุช่องว่าง `[1]`, `[2]` ในข้อความ) |
| `order` | ลำดับข้อ |
| `points` | คะแนนของข้อนี้ |

> `short_answer` ผู้สอนตรวจเองเสมอ

### `Choice` — ตัวเลือก (mcq / true_false / dropdown) · ตาราง 4.9
| field | เก็บอะไร |
|---|---|
| `question` | ของคำถามข้อไหน |
| `blank_no` | ช่องว่างที่ตัวเลือกนี้สังกัด (เฉพาะ dropdown) |
| `text` | ข้อความตัวเลือก |
| `is_correct` | เป็นคำตอบที่ถูกไหม |
| `order` | ลำดับตัวเลือก |

### `MatchingPair` — คู่จับคู่ที่ถูกต้อง (matching) · ตาราง 4.10
| field | เก็บอะไร |
|---|---|
| `question` | ของคำถามข้อไหน |
| `left_text` | ข้อความฝั่งซ้าย (โจทย์) |
| `right_text` | ข้อความฝั่งขวา (คำตอบที่คู่กัน) |
| `order` | ลำดับคู่ |

### `QuizAttempt` — การเข้าทำแบบทดสอบ 1 ครั้งของผู้เรียน 1 คน · ตาราง 4.11
| field | เก็บอะไร |
|---|---|
| `quiz` | ทำแบบทดสอบไหน |
| `student` | ใครทำ |
| `attempt_number` | ครั้งที่เท่าไหร่ (1, 2, 3…) |
| `status` | `in_progress` / `submitted` / `auto_submitted` / `graded` |
| `started_at` | เริ่มทำเมื่อไหร่ (เซิร์ฟเวอร์บันทึก) |
| `due_at` | ต้องส่งก่อนเวลานี้ (บันทึกตอนเริ่ม = min(started_at + เวลาจำกัด, available_until)) |
| `submitted_at` | ส่งเมื่อไหร่ |
| `score` | คะแนนที่ได้ (หลังตรวจ) |
| `graded_at`, `graded_by` | ตรวจเสร็จเมื่อไหร่ / ผู้ตรวจ (กรณีมีอัตนัย) |

### `Answer` — คำตอบ 1 ข้อ ต่อ 1 คำถาม ต่อ 1 attempt · ตาราง 4.12
| field | เก็บอะไร |
|---|---|
| `attempt` | ของการทำครั้งไหน |
| `question` | ตอบคำถามข้อไหน |
| `response` | คำตอบจริง (JSONB) — รูปแบบตามชนิดคำถาม |
| `is_correct` | ถูกไหม (ว่าง = ยังไม่ตรวจ ; dropdown = ถูกครบทุกช่อง) |
| `points_awarded` | ได้กี่คะแนน (dropdown / matching คิดตามสัดส่วนที่ถูก) |
| `feedback` | ความเห็นผู้สอน (อัตนัย) |

รูปแบบ `response`: mcq/true_false → `{"choice_id": 501}` · dropdown → `{"blanks": {"1": 511, "2": 514}}` · matching → `{"pairs": {"<left_id>": right_id}}` · short_answer → `{"text": "..."}`

|---|---|

### `GradeItem` — 1 คอลัมน์คะแนนในสมุดคะแนน · ตาราง 4.18
| field | เก็บอะไร |
|---|---|
| `course` | ของวิชาไหน |
| `category` | อยู่หมวดไหน (ว่าง = ยังไม่จัดหมวด → ไม่นับในคะแนนรวม) |
| `title` | ชื่อคอลัมน์ |
| `max_score` | คะแนนเต็มของคอลัมน์นี้ |
| `quiz` | แบบทดสอบต้นทาง (ว่าง = ไม่ได้มาจากแบบทดสอบ) |
| `assignment` | งานต้นทาง (ว่าง = ไม่ได้มาจากงาน) |
| `order` | ลำดับ |

> `quiz` และ `assignment` ว่างทั้งคู่ = ช่องที่ผู้สอนกรอกเอง ; ภายในหมวดคิดตามสัดส่วนคะแนนเต็ม ; ผู้เรียนเห็นคะแนนทันทีเมื่อบันทึก

### `Score` — คะแนนของผู้เรียน 1 คน ต่อ 1 คอลัมน์ · ตาราง 4.19
| field | เก็บอะไร |
|---|---|
| `grade_item` | คอลัมน์ไหน |
| `student` | ของใคร |
| `raw_score` | คะแนนดิบ (จากการตรวจ หรือผู้สอนกรอกเอง) |
| `adjusted_score` | คะแนนที่ผู้สอนปรับแก้ (ถ้ามี ใช้ตัวนี้แทน) |
| `comment` | หมายเหตุ (ว่างได้) |
| `source_attempt` | มาจากการทำแบบทดสอบครั้งไหน |
| `source_submission` | มาจากการส่งงานไหน |

> คะแนนรวมแบบถ่วงน้ำหนักคำนวณสดจากตารางนี้ทุกครั้ง — ไม่เก็บในฐานข้อมูล ; **นับเฉพาะช่องที่มีคะแนนแล้ว** และแสดง 2 ตัวเลข: ผลการเรียนตอนนี้ (%) + คะแนนสะสม (จาก 100)
